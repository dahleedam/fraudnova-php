> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `fraudnova/fraudnova-php`, the official Composer client for the FraudNova API, in the new repository `/Users/dahleedam/Herd/fraudnova-php`, ready for the owner to push and register on Packagist.

**Architecture:** One thin `FraudNova\Client` delegates every HTTP concern to `FraudNova\Http\Transport` (request building, PSR-18 send, JSON decoding, status → exception mapping, opt-in 429 retry) and maps the decoded envelopes into `final readonly` result objects under `FraudNova\Result`. Discovery of a PSR-18 client happens lazily in `FraudNova\Http\HttpClientDiscovery`. An optional Laravel bridge under `src/Laravel` binds the client from `config/fraudnova.php`.

**Tech Stack:** PHP ^8.2; runtime deps only `psr/http-client`, `psr/http-factory`, `psr/http-message`; dev: PHPUnit ^11.5||^12, PHPStan ^2 (level max), Laravel Pint, nyholm/psr7, Guzzle 7, symfony/http-client, orchestra/testbench ^9||^10||^11; GitHub Actions.

## Review Focus

1. Base URL given with a trailing slash (`https://fraudnova.com/api/v1/`) → requests still go to `…/api/v1/check`, never `…//check`. (Test in Task 3.)
2. An API key with surrounding whitespace is trimmed; an empty or whitespace-only key throws `InvalidArgumentException` from the constructor, so the SDK never sends `Authorization: Bearer ` with nothing after it. (Test in Task 6.)
3. Subjects that need percent-encoding (`user+tag@example.com`, IPv6 `2001:db8::1`, a phone typed as `+1 (817) 679-1808`) arrive at the API intact: the query is RFC 3986 encoded. (Test in Task 6.)
4. A 429 with a non-JSON (Cloudflare HTML) body is still a `RateLimitException` with `isConcurrencyLimit() === false`, so the rate-limit retry schedule applies and nothing crashes on the missing envelope. (Test in Task 2.)
5. A batch envelope whose `results` key is missing or not a list throws `UnexpectedResponseException` (status 200) instead of silently returning zero items. (Test in Task 6.)
